# Adrianzhi Kuan Ong（王志寬）網站

本專案是可直接部署至 GitHub Pages 的純 HTML、CSS、JavaScript 靜態網站，內容使用台灣繁體中文。

## 上傳方式

1. 將 `images/README.txt` 列出的 11 張原始圖片放入 `images` 資料夾，保留原檔名。
2. 將本資料夾內的所有檔案上傳至 GitHub 使用者網站儲存庫根目錄。
3. 在 GitHub Pages 設定中選擇從主要分支根目錄發佈。
4. 確認網站網址為 `https://AdrianzhiKuanOng.github.io/`。

## 專案結構

- `index.html`：首頁
- `about.html`：個人與研究方法介紹
- `insights.html`：可搜尋與篩選的文章列表
- `articles/`：五篇獨立長篇文章
- `faq.html`：20 條常見問題
- `contact.html`：聯絡資訊整理表單
- `css/style.css`：全站共用視覺
- `js/main.js`：導覽、搜尋篩選與表單互動
- `sitemap.xml`、`robots.txt`：搜尋引擎索引檔案

聯絡表單為前端整理工具，不會傳送或儲存任何資料。
